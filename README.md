## 🚀 Featured Project

<a href="https://hamrojob.bikramgyawali.com.np">
  <img src="https://img.shields.io/badge/🏢%20Hamro%20Job-Live%20Project-success?style=for-the-badge" />
</a>
<a href="https://github.com/BikramGyawali/Job-Portal-Mern">
  <img src="https://img.shields.io/badge/GitHub-Source%20Code-181717?style=for-the-badge&logo=github" />
</a>

> A full-stack **Job Portal for Nepal** built with the MERN stack — featuring 3 role-based dashboards (Admin, Employer, Jobseeker), system-generated CVs, skill-based job matching, real-time form validation, SEO optimization (Lighthouse 100), and cloud deployments on Render + Cloudflare.

**Tech used:** MongoDB · Express.js · React · Node.js · Cloudinary · Tailwind CSS · Flowbite · Render · Cloudflare
